How agents get a quote: MCP and WebMCP, step by step

Voyara exposes one Quote API to AI agents in two ways. A headless agent such as Claude talks to an MCP server over HTTP. An agent built into the browser uses WebMCP tools that the quote page registers itself. Pick a tour and press Next. Every step sends real requests to the running server and shows exactly what went over the wire.

The server is not answering. Start it with cd server && uv run voyara-server, then press Run again.

    Inside the agent: what the model sees

    The model never speaks MCP or WebMCP. The agent translates both ways: tool definitions into the model's tools list and system prompt, the model's tool_use into a tool call, and the result back into a tool_result. Model-side payloads follow the Anthropic Messages API format and are illustrative; the tool payloads inside them are the real ones from this run.

    On the wire for this step

    Real requests and responses. JSON-RPC goes to /mcp, REST to /api. WebMCP tool calls stay inside the browser.
